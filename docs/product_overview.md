# Product Overview

Our platform is a sales-automation suite for B2B SaaS companies. It automates
outreach sequencing, lead qualification, and CRM data enrichment so sales teams
spend more time talking to qualified buyers and less time on manual research.

## Plans

- **Starter**: up to 3 seats, 500 enriched leads per month, email support.
- **Growth**: up to 20 seats, 5,000 enriched leads per month, CRM integrations
  (HubSpot, Salesforce), priority support.
- **Enterprise**: unlimited seats, custom enrichment volume, dedicated onboarding,
  SSO, and a named account manager.

## API Rate Limits

The public API allows 100 requests per minute per API key on the Growth and
Enterprise plans. Starter plan keys are limited to 20 requests per minute.

## Support Hours

Standard support is available 9am-6pm Singapore time, Monday through Friday.
Enterprise customers get 24/7 support with a 1-hour response SLA for critical issues.
